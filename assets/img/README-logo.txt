Drop the official LOVEBITES logo in this folder as:

    assets/img/lovebites-logo.svg      (preferred)
  or assets/img/lovebites-logo.png

The page looks for that file and uses it for the hero wordmark and the
navigation bar automatically. If the file is absent, the site falls back to
the typographic wordmark set in Cinzel, which is the current behaviour.

Nothing else needs changing - see .brand-mark in assets/js/app.js.
